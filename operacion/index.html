¿Cómo funciona esta orden? · Guía rápida
  1. Revisa los datos y cambia el estado de la moto.
  2. Para identificar la moto, pulsa Imprimir comanda para la moto. No incluye precios.
  3. Para cobrar al cliente, añade cada trabajo o refacción y pulsa Guardar desglose de precios.
  4. Descarga o comparte la nota PDF para el cliente, que sí incluye el total.
