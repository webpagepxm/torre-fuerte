TORRE FUERTE — REDISEÑO MULTIMARCA V4

1. Abre index.html con Chrome.
2. Este paquete contiene los assets nuevos en assets/. Para GitHub sube index.html, assets/ y torre-fuerte.vcf (todo lo de la carpeta, no el ZIP).
3. En GitHub: repositorio torre-fuerte > Add file > Upload files > arrastra archivos > Commit changes.
4. Espera Actions verde y comprueba formulario y botones.
