IMPORTANTE SOBRE RESEÑAS
El enlace proporcionado abre la ficha compartida de Google. NO se ha
verificado que despliegue directamente el formulario de reseña. Por eso
la página guía a la persona a tocar «Reseñas → Escribir una reseña».
Para un botón que abra el formulario de manera directa, pide al dueño del
perfil Google Business Profile el enlace «Solicitar reseñas» y sustitúyelo
en todos los lugares donde aparezca el enlace de share.google.

IMPORTANTE SOBRE LAS IMÁGENES Y LOS SERVICIOS
Las fotos de moto en playa y del mecánico son imágenes ambientales
GENERADAS para ilustrar el diseño. NO muestran al taller real ni trabajos
que este haya realizado. Se recomienda reemplazarlas con fotos reales.

PUBLICACIÓN / ACTUALIZACIÓN EN GITHUB
1. Descomprime el ZIP.
2. Entra a github.com/jethromoraless/torre-fuerte
3. En la pestaña Code elige Add file → Upload files.
4. Arrastra TODOS los archivos y la carpeta assets de este proyecto.
5. Confirma los reemplazos / Commit changes.
6. Mantén GitHub Pages conectado a la rama main / (root).
7. La página conservará https://jethromoraless.github.io/torre-fuerte/

Para evitar archivos viejos que ya no se usan, puedes borrarlos después
(si tienen nombres costa-moto.svg, taller-detalle.svg o vista-previa.html).
